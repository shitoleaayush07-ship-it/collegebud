# CollegeBud

**Budget • Tasks • Schedule** – A simple, private web app for college students.

All your data stays in **your browser** (localStorage). Nothing is sent to any server.

## Live Demo

Once you enable GitHub Pages, your site will be at:

**https://shitoleaayush07-ship-it.github.io/collegebud/**

## Features

### 📊 Dashboard
- Current balance overview
- Pending tasks count
- Upcoming events
- Spending pie chart
- Today’s schedule + high-priority tasks

### 💰 Budget
- Add income & expenses
- Categories (Food, Transport, Books, Fees, etc.)
- Running balance
- Doughnut chart of expenses by category
- Delete transactions

### ✅ Tasks
- Add tasks with priority (High / Medium / Low)
- Due dates
- Mark complete / incomplete
- Filter: All / Pending / Done

### 📅 Schedule
- Add classes, exams, meetings, personal events
- Start & end time
- Filter by date
- Upcoming events list

## How to enable GitHub Pages (so the website goes live)

1. Go to your repository: https://github.com/shitoleaayush07-ship-it/collegebud
2. Click **Settings** → **Pages** (left sidebar)
3. Under **Source**, select **Deploy from a branch**
4. Branch: `main` → Folder: `/ (root)` → Click **Save**
5. Wait 1–2 minutes. Your site will be live at:
   `https://shitoleaayush07-ship-it.github.io/collegebud/`

## How to use / edit the code

- Open `index.html` in the repo.
- Everything is in **one file** (HTML + Tailwind + JavaScript).
- You can edit it directly on GitHub or clone the repo and edit locally.

```bash
git clone https://github.com/shitoleaayush07-ship-it/collegebud.git
cd collegebud
# open index.html in any browser or code editor
```

## Tech used
- Pure HTML + CSS + JavaScript
- Tailwind CSS (CDN)
- Chart.js (CDN)
- Font Awesome icons
- localStorage for data persistence
